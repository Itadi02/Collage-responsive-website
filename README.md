# 🎓 University Website

A modern and responsive **University Website** built using **HTML, CSS, JavaScript, and GSAP animations**.  
This project showcases a complete educational institution landing page with smooth animations, responsive navigation, and multiple informative sections.

---

## 🚀 Features

- 🏫 Responsive university landing page
- 📚 Courses section (Intermediate, Degree, Post Graduation)
- 🌍 Global campus showcase
- 🏢 Facilities section
- ⭐ Student testimonials
- 📱 Mobile-friendly navigation menu
- ✨ Smooth animations using **GSAP & ScrollTrigger**
- 📌 Call-to-action section

---

## 🛠️ Tech Stack

- **HTML5** – Semantic structure  
- **CSS3** – Styling, Flexbox & Media Queries  
- **JavaScript** – DOM manipulation & menu toggle  
- **GSAP** – Animations & scroll effects  
- **Font Awesome & Google Fonts** – Icons & typography

## ⚙️ How It Works

- Navigation menu toggles on smaller screens using JavaScript
- GSAP handles:
  - Page load animations
  - Scroll-based animations
- Fully responsive layout using media queries
- Clean UI focused on readability and presentation

- Event handling
- Responsive menu toggle
- GSAP timelines
- ScrollTrigger animations
